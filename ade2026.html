About this guide

Built around the city.

This is an independent discovery interface using event details published in the official ADE 2026 programme. It is not an official ADE product. Each event links back to its source listing, where ticketing, changes and further details should be checked.

The event dataset is embedded in this file and does not update automatically. Venue coordinates are looked up using OpenStreetMap's Nominatim service at runtime; geocoding can fail or return no result. No coordinates have been hard-coded as verified when they could not be independently confirmed during research.

Research sources

Coverage is selective, not exhaustive. Event information and lineups may change; the official event page remains the authoritative reference.
